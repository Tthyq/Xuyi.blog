## 项目背景

想要一个不依赖云端、本地可控的智能家居方案。市面上的方案要么贵（Home Assistant 专用硬件），要么隐私堪忧（各类国产智能家居平台）。

**目标**：用一块 ESP32 开发板，搭建一个低成本的本地智能家居网关。

## 硬件选型

| 组件 | 型号 | 成本 |
|------|------|------|
| 主控 | ESP32-WROOM-32 | ¥25 |
| 射频模块 | CC1101 (433MHz) | ¥12 |
| 温湿度 | DHT22 | ¥10 |
| 继电器 | 4路 5V 低电平触发 | ¥15 |

总成本不到 ¥70，比任何成品方案都便宜。

## 固件架构

```
┌─────────────────────┐
│    HTTP / WebSocket  │  ← 本地 Web 控制面板
├─────────────────────┤
│    任务调度器 (FreeRTOS) │
├─────────┬───────────┤
│ 传感器池 │ 执行器池    │
├─────────┴───────────┤
│ MQTT 客户端 (本地 Broker)│
├─────────────────────┤
│ WiFi + 低功耗管理 (ESP-NOW)│
└─────────────────────┘
```

## 踩坑记录

### WiFi 重连死锁

在 deep sleep 唤醒后，WiFi 重连有时会卡死。原因是 `WiFi.begin()` 在特定情况下不会返回。解决方案：增加超时看门狗，30 秒未连上则硬重启。

### MQTT QoS 选择

起初用了 QoS 2，结果 ESP32 的内存被 retain message 撑爆。降级到 QoS 1 + 本地判断去重，完美解决。
